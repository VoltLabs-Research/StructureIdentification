# Structure Identification Library

Shared reconstructed-state and cluster-graph library used by CNA, PTM, PSM, Elastic Strain and OpenDXA.

## Install

This is an internal shared library, not a vpm-installable workflow plugin. It is consumed as a Conan dependency by the analysis plugins (CNA, PTM, PSM, Elastic Strain, OpenDXA) and is pulled in automatically when you install those.
